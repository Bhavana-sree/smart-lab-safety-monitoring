# Smart Lab Safety Monitoring using ML and IoT

## Overview
Smart Lab Safety Monitoring is a Django-based web application integrated with Machine Learning and IoT concepts to monitor laboratory safety conditions and detect potential hazards.

The system helps improve laboratory safety by monitoring environmental conditions and generating alerts for unsafe situations.

---

## Features
- Real-time safety monitoring
- Machine Learning-based prediction
- Django web dashboard
- Sensor data analysis
- Alert generation system
- Data storage using SQLite

---

## Technologies Used
- Python
- Django
- Machine Learning
- SQLite
- HTML/CSS
- IoT Concepts

## How to Run the Project

### Step 1: Clone Repository

```bash
git clone https://github.com/Bhavana-sree/smart-lab-safety-monitoring.git
```

### Step 2: Open Project Folder

```bash
cd smart-lab-safety-monitoring
```

### Step 3: Run Server

```bash
python manage.py runserver
```
